# Archived documentation

These files apply only to builds before 1.6.0, which used Firebase (App Check,
AI Logic) and Gemini for camera scanning:

* [AppCheck_PlayIntegrity_Setup.md](AppCheck_PlayIntegrity_Setup.md)
* [AppCheck_Enforcement_Step1.md](AppCheck_Enforcement_Step1.md)
* [AppCheck_CostHardening_Step2.md](AppCheck_CostHardening_Step2.md)

They are kept as a historical record. Version 1.6.0 replaced those services with
the bundled, offline Hearth models; current builds contain no Firebase, Google
Play Services or network access. See [native offline OCR](../Hearth_OCR.md) for
the current implementation.
